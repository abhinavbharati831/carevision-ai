# CareVision AI  
## Intelligent Heart Disease Analytics and Prediction Platform

CareVision AI is an advanced AI-powered healthcare analytics platform developed using Machine Learning and Flask web technologies. The platform predicts heart disease risk using patient healthcare parameters and provides intelligent healthcare analytics through an interactive dashboard system.

# Project Overview

CareVision AI is designed to assist in early heart disease risk detection by integrating Machine Learning prediction systems with real-time healthcare analytics visualization.

Unlike traditional healthcare prediction systems, CareVision AI provides:

- AI-powered heart disease prediction
- Risk probability analysis
- Confidence scoring
- Explainable AI recommendations
- Interactive healthcare dashboard
- Real-time healthcare analytics
- Modern cyber-healthcare UI
- Data visualization and chart analytics

The project demonstrates the practical implementation of Artificial Intelligence and Machine Learning technologies in healthcare analytics and predictive healthcare systems.

# Installation

## Clone Repository

```bash
git clone https://github.com/abhinavbharati831/carevision-ai.git
```

## Navigate to Project Folder

```bash
cd carevision-ai
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run Project Locally

```bash
python main.py
```

Open browser:

```bash
http://127.0.0.1:5000
```
